# Sound datasets

## background_sounds

contains environmental noise such as bird, cars, river, truck, wind.
support mono, mono-5s, stereo

## dronetest

all kinds sound tracks has drone sound in them.

## gh-cwt-plot-ds

contains 16 types of grasshopper train/val/test cwt plot dataset based on 
'grasshopper_train-ds'.

## gh-drone-inference

test data for grasshopper + bird + drone noise or separation.

## grasshopper-aug-ds

contains 16 types of grasshopper 2 second mono 44.1K sampling rate wav file dataset 
(roughly 100 samples each type) based on 'grasshopper_raw-ds'.

## grasshopper-raw-ds

contains 16 types of grasshopper 2 second mono 44.1K sampling rate wav file dataset 
(samples count varies for each type, 2 - 38). gh-14 has the most 38 and gh-13 
has the least 2.

## grasshopper-sound-4

this folder contains the gh-1 to gh-7 sounds, picture, cwt plots, meta yaml

## grasshopper-train-ds

contains 16 types of grasshopper 2 second mono 44.1K sampling rate wav file dataset 
(roughly 70 samples for train, 20 for val, 10 for test) based on 'grasshopper_aug-ds'.

## mix

test data for grasshopper + bird + drone mix sound and cwt plot

## scaper_audio

https://github.com/justinsalamon/scaper

background and foregroud sound tracks for scaper.

## support

sound tracks collected for this project

### insect-sound-lib

96 insect sound

### kaggle_insect_sound

10 insect sound

## Windtest

gh4 sound mix with drone and wind

## xc-chorthippus-5-species

chorthippus (grasshopper) family 5 species

### aug-ds

contains 5 species of grasshopper 2 second mono 44.1K sampling rate wav file dataset 
(roughly 250 samples each type) based on 'raw-ds'.

### plot-ds

contains 5 species of grasshopper train(180)/val(50)/test(25) cwt plot dataset based on 
'train-ds'.

### raw-ds

contains 5 species of grasshopper 2 second mono 44.1K sampling rate wav file dataset 
(gh-18/129, gh-21/82, gh-22/63, gh-23/20, gh-26/37).

### train-ds

contains 5 species of grasshopper train(180)/val(50)/test(25) cwt plot dataset based on 
'aug-ds'.

## xeno-canto-acrididae

more grasshopper sound tracks from xeno-canto
